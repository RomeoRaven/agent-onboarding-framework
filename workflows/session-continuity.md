# Session continuity — portable method

Use at startup, recovery, or closeout when an agent may need context from an earlier session. This method depends on the destination's actual loader, owner sources, task tracker, and retention rules. It is not a universal command list or a replacement for live task state.

## Startup and recovery

1. Begin with the current operator request and native constraints. Follow the verified local startup contract to the manifest and select the governing sources for that request. If a required source or permission is missing, stop consequential work; do not substitute a handoff.
2. Consult compact Tier 1 pointers for discovery only where the runtime loads them. Select Tier 2 owner procedures/skills on demand, checking compatibility and status. Do not preload the full library.
3. Read a dated Tier 3 note or handoff only when it materially helps recover the selected work. Separate observation, unresolved claim, suggested next step, and actual current owner state. Verify old statuses, permissions, and links from live owners. An unreliable session's inferred objective cannot become the next session's directive.

## During work and closeout

Work from the current task owner and record live outcomes there. Use a dated continuity note when a long or interrupted session needs recoverable observations, not as a second tracker. At closeout, create a dated handoff only if restart context changed or cross-agent recovery truly needs it. Include the objective, current owner links, what was verified and how, open blocker, material uncertainty, sensitive-data classification, and a clearly non-authoritative suggested restart. Keep any `latest` pointer minimal and local. Do not copy credentials, raw private context, or stale task lists.

## Validation and failure

A fresh agent should be able to locate the selected owner, distinguish a handoff from authority, and resume a bounded task after verifying old claims. If the handoff conflicts with the live owner or its access/provenance is unclear, prefer the live owner where authority is established and report unresolved material conflicts before consequential action. Do not claim continuity merely because a dated file exists. Any actual write or external result is verified in its owning surface.
